# 에이전트 개입 가시성

서비스의 `/agents` 화면에서 분석 → 조건부 자동 검토 → 사람의 결정 흐름과
각 역할의 개입 조건, 입력 근거, 제공 의견, 사용 화면을 확인할 수 있다.
5개 역할이 자동 연결되며 A4 웨이버 심사관은 자동 연결되지 않은 상태로 표시한다.
가이드 자체는 실시간 연결 상태나 실행 이력이 아니다.

## 분석·프로젝트 화면

- 분석 실행 전에 담당 에이전트와 호출 조건을 표시한다.
- 검토 카드에 조건과 실제 결과의 위반 수, WNS, IR-drop, 글리치 비중 또는 선택 스테이지를 표시한다.
- 실행 전, 조건 확인/응답 대기, 조건 미해당, 검토 완료, 검토 미완료를 구분한다.
- 완료에는 서버의 UTC 완료 시각을 사용자의 현지 시각으로 표시하고 처리 시간과 검토 식별자를 제공한다.
- 게이트는 A5 → V 순서로 처리하고 두 응답을 함께 표시한다. 서버 응답 전에는 특정 역할이
  실제 실행 중이라고 단정하지 않는다. A5 실패 시 V 생략과 통신 실패 시 실행 여부 확인 불가를 구분한다.
- 재시도는 게이트의 종합·검증 전체를 다시 실행한다. 새 게이트 근거가 도착하면 이전 의견은 표시하지 않는다.
- 주요 게이트 차단 사유를 한국어로 표시한다.

`completed_at`, `duration_ms`, `review_id`는 실제 시도에만 추가된다.
조건 미해당 응답에는 실행 메타데이터가 없다. 실패의 `review_id`는 로그 문의용 `error_id`와 같다.
검토 완료는 설계 통과나 승인 완료가 아니다. 분석 화면의 자동 검토 의견은 DB 이력으로
저장되지 않는다. 저장된 RTL/OpenSTA 런에서 사용자가 명시적으로 요청한 검토는 요청자,
당시 입력·지침·의견·상태를 보존하며 JSON 다운로드를 제공한다.
자세한 범위는 [저장 검토](saved-run-reviews.md)를 참조한다. 승인·웨이버 변경 이력은 별도다.
