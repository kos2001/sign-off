# DRC 마커 탐색

KLayout 보고서를 저장한 뒤 **DRC 마커 탐색**으로 이동한다.
프로젝트의 해당 런에서도 같은 링크를 제공한다. 주소는 `/runs/{run_id}/markers`다.

## 조회와 검색

- viewer 이상의 프로젝트 조회 권한으로 보관된 마커를 읽는다.
- 마커는 원본 보고서 순서이며 중복을 합치지 않는다. 기본 페이지는 25개다.
- 검색은 규칙 분류·셀·값·태그·댓글의 대소문자 무시 부분 문자열이다.
  `%`, `_`를 검색 패턴으로 해석하지 않는다.
- 규칙/셀 필터는 원문의 정확한 값을 사용한다. 셀 이름이 빈 전역 마커도 선택할 수 있다.
- 필터 옵션의 개수는 전체 보고서 기준이다. 검색 결과 개수와 그 결과의 multiplicity 합계는 별도 표시한다.
- q/category/cell/offset/selected를 URL에 보존한다. 상세의 selected 번호는 필터와
  독립적인 원본 마커 번호다. UI에서 검색 조건을 바꾸면 선택과 페이지를 초기화한다.
- 현재 위반 처리 상태와 원본 마커는 별개다. 원본 태그를 승인 상태로 해석하지 않는다.
  조회는 AI를 호출하거나 상태를 변경하지 않는다. 연결된 위반은 아래 별도 검토 절차로 처리한다.

API: `GET /runs/{id}/markers`, `GET /runs/{id}/markers/{marker_index}`.
목록에는 값 문자열을 싣지 않고 요약만 반환한다. 상세에서 원문과 기하 미리보기를 제공한다.
원본 KLayout 근거가 없는 런은 409, 없는 마커는 404, 범위 밖 마커 번호는 422다.

## 셀 좌표 미리보기

box, edge, edge-pair, polygon(구멍 포함)을 지원한다. 좌표 단위는 µm이고
X는 오른쪽, Y는 위쪽이다. 축 비율을 동일하게 유지하여 선택된 마커를 화면에 맞춘다.
셀 계층 변환, GDS/OASIS 레이아웃 배경, 실제 배선 문맥은 포함하지 않는다.
따라서 레이아웃 검증이나 전체 DRC 통과의 증거로 취급하지 않는다.

숫자는 Decimal로 읽고 경계·차이·정규화를 계산한 다음 SVG 화면 좌표로 변환한다.
큰 원점 근처의 작은 도형을 먼저 부동소수점으로 빼면서 잃는 문제를 피한다.
원래 좌표 문자열과 표시 범위를 함께 제공하며 원문을 변경하지 않는다.

지원 숫자는 64자 이하이며 절댓값 10^12 µm 이하, 0이 아니면 10^-12 µm 이상이다.
마커당 2,000개의 점을 표시한다. 한 값이 한도를 넘으면 그 값 전체를 미표시로 분류한다.
텍스트·미지원 형식·유효하지 않거나 범위 밖인 값은 도형으로 추정하지 않는다.
표시된 값 수와 미표시 값 번호를 명시하고 모든 원문을 계속 보여준다.

## 검증

관련 API·파서·인증 테스트 47개와 프런트엔드 빌드 통과.
실제 KLayout edge-pair 좌표, 축 방향·비율, polygon 구멍, 퇴화한 선분,
큰 원점/작은 차이, 비유한·범위 밖 숫자, 표시 점 제한을 확인했다.
권한·문자열 검색·전역 셀·페이지 순회·원본 불변성도 포함한다.

`scripts/browser_markers_check.mjs`는 임시 인증 DB에서 실제 KLayout 생성 기하와
합성한 페이지/텍스트/구멍 도형 fixture를 사용한다. 조회 전용 사용자로 검색·분류·페이지,
원문 전용 표시·공유 URL 복원·edge-pair SVG 좌표·polygon 구멍·320/390/1440px를 검증했다.

## 연결된 위반의 현재 상태와 검토

상세의 `violation_matches`는 같은 런에서 `klayout/<지문 앞 32자리>`와 일치하는
위반 ID·상태·버전을 반환한다. 원본 마커와 위반이 각각 하나일 때만 `unique`다.
같은 지문이 반복되거나 후보가 여러 개면 `ambiguous`로 표시하고 전체 후보를 제공한다.
후보가 없으면 `missing`이며 해결된 상태로 간주하지 않는다. 중복 발생 수·태그·댓글이
다른 마커도 분류·셀·값이 같으면 같은 지문일 수 있어 일대일 대응을 추정하지 않는다.

화면은 모호한 경우 위반을 자동 선택하지 않는다. 후보를 25건씩 보여주며 번호·설명·이력을
확인한 뒤 개별 기록을 선택한다. 선택한 위반의 현재 상태는 5초 간격으로 확인한다.
원본 마커의 방문/waived 태그는 서비스 상태와 계속 구분한다.

viewer는 조회·이력 확인만 가능하다. editor는 수정 완료·재오픈, approver 이상은 웨이버
승인·해제를 기존 절차로 처리한다. 사유·서버 인증 계정·버전 비교·변경 이력을 재사용하며
여러 후보를 한꺼번에 변경하지 않는다. 원본 마커·기하·런 판정은 바뀌지 않는다.
최신 상태 갱신이 입력 폼의 포커스를 다시 가져가지 않도록 했으며, 다른 사용자가 상태를
바꾸면 작성 사유를 보존하고 버전 충돌로 저장을 막는다.

검증: 관련 테스트 45개, 빌드, `scripts/browser_marker_review_check.mjs` 임시 인증 DB 검증.
중복 3개 중 하나씩 선택, viewer/editor/approver 권한, 다른 검토자의 승인 후 초안 보존,
개별 승인·이력, 원본 불변성과 320/390/1440px 배치를 확인했다.
